# 7DT effective medium-band transmission curves (2026-09-10)

One file per filter (`lam` nm, `trans`): filter-only curve shifted by the fitted effective shift and multiplied by the
filter-independent system factor S(lambda) (QE x optics x atmosphere at airmass X0, same as the nominal curves).
`curves_metadata.csv` gives the shift, its uncertainty, the class (determined / prior+continuum / undetermined / predicted)
and flags per filter; `model_params.json` the global prior (k = dlambda/lambda, tau) and the beam model (n_eff, eps).
